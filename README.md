## ✨ 核心特性

- 🎯 **方便 (Convenient)**：
  - **Spotlight 极速呼出**：随时按下 `Cmd/Ctrl + K` 呼出快速录入弹窗，随想随记。
  - **桌面悬浮迷你便签 (Mini Sticky Mode)**：一键收缩为桌面边缘小窗小组件，置顶悬浮在屏幕角落，随时随地打勾划掉待办。
  - **全键盘极速流**：按 `1~5` 切换核心视图，`Esc` 退出弹窗，单行回车秒建任务。
  - **系统托盘驻留**：支持关闭最小化到系统托盘，不占任务栏空间。

- ⚡ **简单 (Simple)**：
  - **极简层次结构**：清晰划分「☀️ 我的一天」、「📥 收集箱」、「📅 近期安排」、「📦 全部任务」、「✅ 已完成归档」。
  - **拒绝冗余复杂**：主干信息一目了然，点击任务才滑出右侧深度详情抽屉（子步骤、备忘）。
  - **零学习门槛**：单文件数据库，开箱即用，断网秒开。

- 🎨 **美观 (Aesthetic)**：
  - **暗黑磨砂玻璃质感 (Glassmorphism)**：延续轻奢流光暗夜风格，多层微光描边与高保真毛玻璃虚化。
  - **任务完成五彩礼花**：打勾完成待办时，触发丝滑震动音效与 `canvas-confetti` 绚丽礼花喷洒！
  - **呼吸感动态环形进度条**：番茄专注钟与今日待办完成率拥有优雅的平滑动画。

- 🛠️ **实用 (Practical)**：
  - **自然语言智能解析 (NLP Smart Input)**：
    - 输入：`明天下午3点 提交技术方案 !高 #工作 *2`
    - 自动识别并拆解：标题、截止时间（明天 15:00）、优先级（P1 紧急重要）、分类标签（#工作）、预估番茄数（2个）！
  - **四象限时间管理矩阵 (Eisenhower Matrix)**：第一至第四象限直观划分，支持直接跨象限拖拽流转任务。
  - **看板工作流 (Kanban Board)**：待处理、进行中、等待/搁置、已完成 4 列看板，拖拽自如。
  - **内置番茄专注钟 (Pomodoro)**：
    - 25 分钟专注 / 5 分钟短休 / 15 分钟长休
    - 纯 Web Audio 算法实时合成优雅的起止颂钵钟声与心流白噪音，无外部静态音频依赖。
  - **子任务清单 (Checklist)**：复杂任务支持一键拆解多级子步骤推进。
  - **数据私有化与备份**：内置 SQLite 数据库，支持一键导出/恢复完整 JSON 备份，群晖 NAS Docker 一键部署。

## 🚀 快速启动

### 1. 开发调试模式 (前后端热重载)

```bash
cd nas-todo

# 1. 安装依赖
pnpm install

# 2. 一键启动后端 API + 前端 Vite (并发监听)
pnpm dev
```

浏览器打开 `http://localhost:5174` 即可体验。

### 2. 生产运行模式 (自托管 / 本地单机)

```bash
# 编译前端并启动全栈服务
pnpm build
pnpm start
```

访问 `http://localhost:3001` 即可使用。

---

## 🐳 群晖 NAS / Docker 一键部署

在项目根目录下直接使用 Docker Compose 启动：

```bash
docker-compose up -d
```

所有待办数据会自动持久化存放在本机的 `./data/todo.db` SQLite 文件中。

## 📦 桌面端原生打包 (Tauri 2.0)

本项目已完整配置 Tauri 2.0 跨平台桌面运行时 (`src-tauri`)。

```bash
# 开发环境预览 (需安装 Rust 工具链)
pnpm tauri:dev

# 构建桌面原生安装包 (macOS .dmg / Windows .exe)
pnpm tauri:build
```

## ⌨️ 常用快捷键

| 快捷键 | 功能 |
|---|---|
| `Cmd / Ctrl + K` | 呼出 Spotlight 风格极速待办录入框 |
| `Cmd / Ctrl + Shift + P` | 呼出 / 切换番茄专注钟 |
| `1` | 切换至「☀️ 我的一天」 |
| `2` | 切换至「📥 收集箱」 |
| `3` | 切换至「📅 近期安排」 |
| `4` | 切换至「🔲 四象限分析矩阵」 |
| `5` | 切换至「📋 任务看板工作流」 |
| `Esc` | 关闭当前弹出的对话框、番茄钟或详情抽屉 |
